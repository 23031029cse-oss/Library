# Math Operations Library

## About
This is a simple Python library used to perform basic mathematical operations.

## Operations
- Addition
- Subtraction
- Multiplication
- Division

## Requirements
- Python 3

## How to Run
Run the following command:

```bash
python main.py
```

## Output
```text
Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2.0
```
